# 냉장고 파먹기 홍보 영상 업로드 가이드

영상(세로 1080×1920, 약 20초, 소리 있음)을 4곳에 올리는 순서와 **그대로 붙여 넣을 문구**예요.

## 영상은 두 가지 버전이에요 (끝 3초 멘트만 달라요)
링크가 걸리는 방식이 곳마다 달라서, 끝 멘트를 맞췄어요.

| 올릴 곳 | 쓸 파일 | 끝 멘트 | 이유 |
|---|---|---|---|
| 인스타 릴스 · 틱톡 · 유튜브 쇼츠 | `fridge-demo.mp4` | "프로필 링크 클릭!" | 글 속 링크가 안 눌려서 프로필(채널) 링크로 보내요 |
| 스레드 | `fridge-demo-link.mp4` | "아래 링크 눌러봐!" | 글에 넣은 링크가 바로 눌려요 |

- 영상 파일(내 PC): `C:\Users\JD\Desktop\클로드코드\site_d\promo_media\` 안의 두 파일
- 서버 반영 후 공개 주소: https://cook.dailyfixpoint.com/promo/fridge-demo.mp4 , https://cook.dailyfixpoint.com/promo/fridge-demo-link.mp4
- 폰으로 옮기는 법: 카카오톡 "나와의 채팅"에 파일 보내기 → 폰에서 저장(가장 쉬움) / 구글 드라이브 / USB

## 공통 규칙 (모든 곳)
1. 쿠팡 링크는 넣지 않아요. 사이트 주소만 써요.
2. 그림·목소리가 AI라는 문구는 꼭 넣어요(아래 문구에 이미 들어 있어요). 각 앱에 "AI 생성/합성 콘텐츠" 표시 스위치가 있으면 켜요.
3. **링크가 눌러지는 곳이 달라요**: 스레드는 글 속 링크가 눌러져요. 인스타·틱톡은 프로필 링크만 눌러져요. 유튜브 쇼츠는 설명·댓글의 링크가 눌러지지 않는 경우가 많아서 **채널 프로필의 링크**를 꼭 달아 두세요(채널 맞춤설정 → 프로필 → 링크 추가).
4. 올리는 시간 추천: 평일 저녁 5~8시(저녁 메뉴 고민하는 시간). 4곳을 한 시간 안에 올리면 편해요.

## 1) 유튜브 쇼츠
**방법 A. 내 PC에서 명령 한 줄(가장 쉬움)**
```
venv/Scripts/python.exe -X utf8 site_d/promo/post_video.py --send --youtube
```
제목·설명·합성 콘텐츠 표시까지 자동으로 들어가요.

**방법 B. 직접 올리기 (PC 브라우저 또는 폰 YouTube Studio 앱)**
1. studio.youtube.com 접속 → 오른쪽 위 **만들기 → 동영상 업로드** → 영상 파일 선택
2. **제목**(복사해서 붙여넣기):
```
냉장고 열었는데 곧 버릴 재료만? 재료 누르면 요리가 바로 나와요 #shorts
```
3. **설명**:
```
냉장고에 있는 재료를 눌러 담기만 하면 지금 만들 수 있는 요리가 바로 나와요. 분량(ml·g)과 순서까지 정리돼 있어요.
👉 https://cook.dailyfixpoint.com/?utm_source=youtube&utm_medium=social&utm_campaign=demo
※ 그림과 목소리는 AI로 만들었고, 요리 사진은 AI로 만든 참고 이미지예요.
#냉장고파먹기 #냉털 #자취요리 #집밥 #레시피 #냉장고정리 #shorts
```
4. **시청자층**: "아니요, 아동용이 아닙니다" 선택
5. **더보기(자세히 보기)** → **변경되거나 합성된 콘텐츠: 예** (AI 목소리·그림이라서)
6. 다음 → 다음 → **공개** 선택 → **게시**
7. 게시 후 **고정 댓글**(내가 단 댓글을 고정):
```
재료 몇 개만 눌러 보세요. 있는 재료로 바로 되는 요리가 나와요 👉 채널 프로필의 링크로 들어오세요 (cook.dailyfixpoint.com)
```
참고: 쇼츠는 썸네일을 따로 못 골라요(영상 첫 화면이 쓰여요).

## 2) 인스타그램 릴스 (폰 앱)
1. 인스타 앱 → 가운데 **＋** → **릴스** → 갤러리에서 영상 선택 → **다음**
2. 오디오/편집은 건드리지 않고 **다음**
3. **문구**(복사해서 붙여넣기):
```
냉장고 열었는데 곧 버릴 재료만 잔뜩? 😇
재료 몇 개만 누르면 할 수 있는 요리가 바로 나와요!
남은 재료 빨리 처분하고 싶으면 프로필 링크에서 cook.dailyfixpoint.com
※ 그림과 목소리는 AI로 만들었고, 요리 사진은 AI로 만든 참고 이미지예요.

#냉장고파먹기 #냉털 #자취요리 #집밥 #레시피 #냉장고정리
```
4. **더 보기(고급 설정) → AI 라벨 추가** 켜기 (그림·목소리가 AI라서)
5. 공유 대상은 **릴스 + 피드에도 공유** 둘 다 켜기 → **공유**
6. **프로필 링크 설정(처음 한 번)**: 프로필 → 프로필 편집 → 링크 추가 → `https://cook.dailyfixpoint.com/?utm_source=instagram&utm_medium=social&utm_campaign=profile`
   (릴스 문구 안의 주소는 눌러지지 않아서 프로필 링크가 꼭 필요해요)
7. 올린 뒤 첫 댓글로 한 줄 달아요: `프로필 링크 눌러서 재료만 골라보세요 🙌`

**자동으로 올리고 싶다면**(서버 반영 후 PC에서):
```
venv/Scripts/python.exe -X utf8 site_d/promo/post_video.py --send --instagram
```

## 3) 스레드
**방법 A. 앱에서 직접**
1. 스레드 앱 → **새 스레드 ＋** → 영상 첨부(사진 아이콘, **`fridge-demo-link.mp4`** 사용) → 아래 글 붙여넣기 → **게시**
```
냉장고 열어보니 곧 버릴 재료만 잔뜩이야… 😇
재료 몇 개만 눌러봐, 할 수 있는 요리가 바로 나와!
남은 재료 빨리 처분하고 싶으면 여기 한번 들어가봐 👉 https://cook.dailyfixpoint.com/?utm_source=threads&utm_medium=social&utm_campaign=demo
```
(스레드는 글 안의 링크가 눌러져요)

**방법 B. 자동**(서버 반영 후 PC에서):
```
venv/Scripts/python.exe -X utf8 site_d/promo/post_video.py --send --threads
```
영상 처리에 몇 분 걸릴 수 있어요.

> 스레드 정기 글(하루 한 편)은 따로 준비돼 있어요: 서버 `.env`에 `SITE_D_PROMO_THREADS=1` 한 줄을 넣으면 켜져요. 켜기 전에는 아무것도 올라가지 않아요.

## 4) 틱톡 (직접 올려야 해요 — 외부 프로그램 업로드는 막혀 있어요)
1. 틱톡 앱 → **＋** → **업로드** → 영상 선택 → **다음**
2. **설명**:
```
냉장고 털기 🧊 재료만 누르면 되는 요리가 바로!
프로필 링크에서 써 봐
※ 그림과 목소리는 AI로 만들었고, 요리 사진은 AI로 만든 참고 이미지예요.
#냉장고파먹기 #냉털 #자취요리 #집밥 #레시피 #냉장고정리
```
3. **더 많은 옵션 → AI 생성 콘텐츠: 켜기**
4. 공개 범위 **모든 사람** → **게시**
5. 프로필 링크는 계정 조건(비즈니스 계정 전환 등)이 필요해요. 안 되면 프로필 소개(바이오)에 `cook.dailyfixpoint.com` 글자로 적어 둬요.

## 자주 겪는 문제
- **영상이 잘려 보임**: 앱이 가로 비율로 열린 경우예요. 세로(9:16)로 다시 선택해요.
- **인스타 업로드가 막힘**: 같은 영상을 여러 번 올리면 걸릴 수 있어요. 30분 쉬고 다시 올려요.
- **유튜브가 "쇼츠"로 안 올라감**: 영상이 60초 이하 세로여야 하고, 제목이나 설명에 `#shorts` 가 있어야 해요(이미 들어 있어요).
- **명령이 "공개 주소가 열려 있지 않다"고 함**: 서버에서 `git pull origin main` 후 `bash scripts/publish_site_d.sh rnwufbzemy` 를 먼저 실행해요.
